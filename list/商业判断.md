# 商业判断

> **产品：** 午托伴侣 · 老师端 MVP  
> **依据：** 托管机构从业者访谈、MVP 功能边界

---

## 1. 付费用户是谁？

**买单的人：** 中小型托管机构负责人（20–80 人规模，兼管班与招生）。  
**使用的人：** 带班老师。采购决策链短，但落地取决于老师是否愿意天天用。

| 角色 | 关系 |
|------|------|
| 机构负责人 | 感知沟通成本与续报压力，**付费决策人** |
| 带班老师 | 午间实际操作；**日常使用情况，影响负责人续费决策** |
| 家长 | 不付费；其满意度间接影响负责人续费意愿 |

MVP 阶段只打 **单店负责人**，连锁、SaaS 集成、摄像头渠道均为后续选项。

---

## 2. 为什么付费？

用户不为「AI」付费，只为 **算得过来的账** 付费。

**（1）降本——省时间**  
现状日均约 30 分钟用于拍照、配文、回复家长（含回复环节，产品暂不覆盖）。**核心播报流程**（拍照 → 生成文案 → 出卡片）目标 ≤15 分钟；全链路是否省时须验证，不宜提前折算为学期节省时长。受访者锚点：**500 元/学期以内可接受**。

**（2）避险——稳续报**  
沟通粗糙或不及时，家长信任下降，直接影响下学期续报。负责人买的是 **「少流失几个学生就回本」**，不是卡片皮肤。

**不构成当前付费理由的：** 无感监控（未闭环）、手动确认（产品底线，非溢价点）。

---

## 3. 如何定价？

### MVP 阶段：单档验证

| 项 | 方案 |
|----|------|
| **计费单位** | 按机构 / 学期 |
| **验证价位** | **¥299–499 / 学期**（访谈上限 500，取中低段试探） |
| **包含能力** | 手拍播报、AI 文案、分享卡片、机构 Logo |
| **试用** | 7 天全功能，或「一餐一卡」体验 |

三档套餐、年付折扣、无感监控加价——**有人愿意付钱之后再设计**。

### 成本边界

API + 部署约 ¥50–100 / 机构 / 学期。定价 ¥399 时毛利空间足够；瓶颈在 **获客与续费**，不在 API 成本。

---

## 4. 如何获客？

### 当前（0 → 5 家）：只要种子

| 动作 | 目的 |
|------|------|
| 母亲托管班标杆试用 | 真实验证 + Before/After 素材 |
| 熟人介绍 1–2 家同类机构 | 验证需求可复制 |
| 本地托管群「免费帮做一张午餐卡」 | 低门槛触达 |

**验证期内不做：** 地推、投流、摄像头渠道捆绑。

### 验证通过后

| 阶段 | 动作 |
|------|------|
| 5–20 家 | 卡片曝光带来自然咨询；老用户推荐 |
| 20 家+ | 摄像头 / 教务 SaaS 渠道；无感监控作溢价项 |
| 续费 | 学期末推送使用数据，绑定续报季话术 |

---

## 结论

| 维度 | 判断 |
|------|------|
| **付费用户** | 单店托管负责人；老师是用工方 |
| **付费动机** | 省时（可算账）+ 稳续报（可感知） |
| **定价** | 单档 ¥299–499 / 学期，验证后再分级 |
| **获客** | 种子 + 口碑，验证期内不扩张 |

商业模式逻辑自洽，访谈给出清晰价位锚点。但 **尚无一人实际付过钱**——须通过 2 周验证中的口头问价或小范围早鸟收单来落地。
